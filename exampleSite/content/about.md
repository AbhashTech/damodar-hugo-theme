Welcome to Damodar! This documentation and engineering notes template is built with performance, clarity, and ergonomics in mind.

## Design Philosophy

1. **Content First**: Typography, line-height, and rhythm tuned specifically for distraction-free technical reading.
2. **Speed & Efficiency**: Zero heavy runtime JavaScript frameworks. Vanilla JS, Hugo Pipes (`resources.Get`, `fingerprint`, `minify`), and modern CSS custom properties.
3. **Ergonomic Navigation**: Sticky desktop sidebar, collapsible section hierarchy, and keyboard-driven search and navigation.
4. **Rich Markdown Features**: Native render hooks for syntax-highlighted code blocks with copy buttons, accessible heading anchors, auto-converting callouts, tabs, and diagrams.

## Key Built-in Tools

- **Dual-Engine Search**: Powered by Pagefind with instantaneous client-side fallback.
- **Speculation Rules API**: Zero-latency page prefetching on mouse hover and touch start.
- **Flicker-Free Theme**: Dual-theme Chroma syntax highlighting with instantaneous dark/light toggle and zero flash of unstyled content.
